# Registry Navigator

Интерактивный дашборд по официальным реестрам и регуляторным источникам из таблицы в Dropbox.

## Запуск

Разместите папку на любом HTTPS-хостинге (например, GitHub Pages или Netlify), затем откройте `index.html` по адресу сайта. Интернет нужен, чтобы сайт загружал актуальную таблицу из Dropbox.

## Как обновляются данные

1. Вносите новые строки в исходную таблицу Excel в Dropbox и сохраняйте файл.
2. При следующем открытии сайта данные подтянутся автоматически.
3. В уже открытом сайте нажмите «Обновить из Dropbox» или подождите до пяти минут — каталог, фильтры и показатели пересчитаются без публикации нового сайта.

Таблица должна быть доступна по ссылке «Все, у кого есть ссылка» и содержать на первом листе следующие колонки:

`Country`, `Area of check`, `Source type`, `Register / Portal`, `Authority`, `What to verify`, `Search by`, `Link`, `Notes`.

Если Dropbox временно недоступен, сайт показывает встроенную сохранённую версию данных и сообщает об этом в шапке.

## Возможности

- поиск по стране, органу, реестру, типу проверки и примечаниям;
- фильтры по стране и категории источника;
- сортировка каталога;
- обзор по странам и типам источников;
- карточка деталей для каждого источника;
- экспорт текущей выборки в CSV.

## Файлы

- `index.html` — страница дашборда;
- `styles.css` — оформление;
- `data.js` — встроенные данные;
- `app.js` — интерактивная логика.
