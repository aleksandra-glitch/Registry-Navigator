# Registry Navigator

Интерактивный дашборд по официальным реестрам и регуляторным источникам из таблицы в Dropbox.

## Запуск

Разместите папку на GitHub Pages, затем откройте `index.html` по адресу сайта. Браузер получает данные с GitHub, поэтому не упирается в ограничения Dropbox.

## Как обновляются данные

1. При первой публикации вставьте актуальную ссылку Dropbox в файл `.github/workflows/sync-dropbox.yml` вместо `ВСТАВЬТЕ_СЮДА_АКТУАЛЬНУЮ_ССЫЛКУ_DROPBOX`.
2. Вносите новые строки в исходную таблицу Excel в Dropbox и сохраняйте файл.
3. GitHub раз в пять минут скачивает файл, обновляет `data.js` и публикует новую версию сайта. На сайте нажмите «Проверить обновления», чтобы увидеть опубликованную версию.

Таблица должна быть доступна по ссылке «Все, у кого есть ссылка» и содержать на первом листе следующие колонки:

`Country`, `Area of check`, `Source type`, `Register / Portal`, `Authority`, `What to verify`, `Search by`, `Link`, `Notes`.

Если Dropbox временно недоступен, GitHub сохраняет последнюю успешную версию данных, поэтому сайт не перестаёт работать.

## Возможности

- поиск по стране, органу, реестру, типу проверки и примечаниям;
- фильтры по стране и категории источника;
- сортировка каталога;
- обзор по странам и типам источников;
- карточка деталей для каждого источника;
- экспорт текущей выборки в CSV.

## Файлы

- `index.html` — страница дашборда;
- `styles.css` — оформление;
- `data.js` — встроенные данные;
- `app.js` — интерактивная логика.
