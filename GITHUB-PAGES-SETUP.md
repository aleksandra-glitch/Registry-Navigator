# Настройка GitHub Pages и синхронизации Dropbox

1. Создайте на GitHub новый публичный репозиторий.
2. Загрузите в его корень все файлы и папки из этого архива, включая `.github` и `scripts`.
3. В **Settings → Pages** выберите **Deploy from a branch → main → /(root)** и сохраните.
4. Откройте файл `.github/workflows/sync-dropbox.yml` через значок карандаша.
5. В строке `DROPBOX_SHARED_URL` замените текст `ВСТАВЬТЕ_СЮДА_АКТУАЛЬНУЮ_ССЫЛКУ_DROPBOX` на актуальную ссылку «Копировать ссылку» из Dropbox. Кавычки сохраните.
6. Нажмите **Commit changes**.
7. Во вкладке **Actions** выберите **Sync registry data from Dropbox** и нажмите **Run workflow → Run workflow**.
8. Когда запуск отметится зелёной галочкой, обновите страницу сайта.

Дальше GitHub будет проверять таблицу раз в пять минут. При добавлении строк в тот же файл Dropbox менять ссылку и файлы сайта не нужно.
